# AI Student Performance Analysis & Prediction System

An interview-friendly AI automation project that:
- Loads student academic data
- Cleans and preprocesses the data
- Trains a machine-learning model
- Predicts whether a student is likely to need support
- Generates an automated report

## Tech Stack
Python, Pandas, Scikit-learn, Joblib

## Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run:
   python main.py

The generated predictions are saved in `outputs/student_predictions.csv`.
